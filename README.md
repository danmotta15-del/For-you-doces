# 🍯 For You Doces

Projeto de desenvolvimento web criado para a For You Doces, com o objetivo de apresentar seus produtos e facilitar o contato com os clientes.

## 🌐 Acesse o site

[Visitar For You Doces](https://danmotta15-del.github.io/For-you-doces/)

## 💻 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Apresentação da marca.
- Catálogo de produtos.
- Seção sobre a empresa.
- Links para contato pelo WhatsApp e Instagram.
- Layout adaptado para dispositivos móveis.

## 🎯 Objetivo do projeto

Aplicar na prática os conhecimentos iniciais de desenvolvimento web adquiridos durante meus estudos em Gestão de TI.

## 📚 Aprendizado

Este projeto representa uma etapa da minha evolução em desenvolvimento web. Foi desenvolvido com prática própria e assistência de inteligência artificial, permitindo exercitar estrutura HTML, estilização CSS, organização de arquivos e publicação de um site.
